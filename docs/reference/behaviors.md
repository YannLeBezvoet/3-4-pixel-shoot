# Behavior reference

> Generated by `npm run schemas` from the engine (`packages/sim/src/behaviors/`). Do not edit by hand: `npm run check` fails when this file is out of date.

Behaviors are engine code. A theme picks one by its id and sets its parameters ([add a theme](../guides/add-a-theme.md)).

## Weapon behaviors

Used in weapons.json.

### `firearm`

A gun firing projectiles from a magazine, with a rate of fire, spread and reload time.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fireMode` | `"auto"`, `"semi"` | required | "auto" fires while the button is held; "semi" fires once per click. |
| `roundsPerMinute` | number > 0, ≤ 3000 | required | Maximum rate of fire. |
| `damage` | whole number > 0 | required | Hit points removed by one projectile. |
| `spreadDeg` | number ≥ 0, ≤ 45 | `0` | Random deviation of each shot, in degrees on each side of the aim. |
| `magazine` | whole number ≥ 1 | required | Rounds per magazine. |
| `reloadMs` | whole number ≥ 0 | required | Reload duration in milliseconds. |
| `reserveMagazines` | whole number ≥ 0 or `null` | `null` | Spare magazines per life; null means unlimited. A reload uses one, and the rounds left in the old magazine are lost. |

## Projectile behaviors

Used in projectiles.json.

### `bullet`

A projectile flying straight at gun height until it hits a character, a solid obstacle or cover it fails to pass, or reaches its range.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `speed` | number > 0, ≤ 6000 | required | Speed in pixels per second (one tile is 48 pixels). |
| `range` | number > 0, ≤ 5000 | required | Distance in pixels from the muzzle after which the bullet disappears. |
