# Pixel Shoot

A top-down twin-stick shooter in pixel art, played in the browser. Arcade gameplay in a serious setting; first theme: the Vietnam War. Solo against bots now, online matches up to 64 participants later.

> Working title. **Status: milestone 0 (foundations) in progress**: there is no game to play yet, but the content pipeline (sprites, themes, translations) works end to end. See the [roadmap](docs/ROADMAP.md).

## Quick start

Requires Node.js 24 or newer.

```
npm install
npm run dev      # http://localhost:5173 — sprite viewer at /dev/sprites
npm run check    # everything CI checks
```
