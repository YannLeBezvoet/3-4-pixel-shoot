## Inspiration

The character style is inspired by the chibi characters of RPG Maker MV/MZ. **No RPG Maker asset is used**, modified or not; all art is original.

## Tools

Sprites are drawn with [Aseprite](https://www.aseprite.org/) and maps built with [Tiled](https://www.mapeditor.org/). Open-source libraries used by the code are listed in each `package.json`.
