# @pixel-shoot/shared

Vector and angle math, seeded random numbers, ids, the `Result` type. Small, dependency-free helpers used by every other package.

- **May depend on:** nothing.
- **Must never:** import any other project package or any platform API.

Other packages import it only through `src/index.ts`. See [ARCHITECTURE §4](../../docs/ARCHITECTURE.md#4-modules-and-dependencies).
